# Mossy Hollow

A short MapleStory-style side-scroller that runs in the browser. Clear the overgrown forest, take the portal into Ember Cave, and defeat the Ember King.

**Play:** https://howard86916.github.io/mossy-hollow/

## How to play

1. Click the game, then press Enter.
2. Defeat 8 monsters in Mossy Hollow to unseal the portal at the far right, then stand in it and press ↑.
3. Defeat 8 monsters in Ember Cave to wake the Ember King, then defeat it.

| Key | Action |
| --- | --- |
| ← → | Move |
| Space / Alt | Jump (↓ + Jump drops through a platform) |
| ↑ ↓ | Climb vines and ropes, use portals |
| Z / Ctrl | Magic Bolt |
| X | Arcane Burst |
| C | Frost Nova (hits up to 6 monsters) |
| V | Shadow Dash |
| R | Magic Roar (hits every monster on the map) |

## Running locally

Open `index.html` in a browser. There is no build step.

## Art

Character, monster, plant, forest and cave art comes from itch.io asset packs: BlueWizard Animations, Slimes, Plant Animations, Mossy Tileset, Cave Assets (Maaot) and Plants Animated. This repo contains resized copies of the parts the game uses; see each pack's itch.io page for its author and license. Effects, HUD and the game code are original.
